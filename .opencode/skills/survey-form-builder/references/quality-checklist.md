# ตรวจสอบคุณภาพก่อนส่งมอบ (Quality Checklist)

รันให้ครบทุกข้อก่อน deploy และก่อนปิดงาน

## เนื้อหา

- [ ] คำถามครบตาม requirement ที่ยืนยันไว้ ไม่เพิ่ม/ลดโดยไม่บอกผู้ใช้
- [ ] ข้อความภาษาไทยถูกต้อง ไม่มี typo ใน label/button
- [ ] คำอธิบายการใช้งานอยู่ตรงที่ต้องใช้ (helper text)

## ฟอร์ม

- [ ] validation ครบทุกคำถามที่บังคับ
- [ ] ข้อความ error เป็นภาษาไทย บอกวิธีแก้
- [ ] คำถาม multiple-choice เลือกได้หลายคำตอบจริง
- [ ] คำถาม rating/scale กดได้ครบทุกระดับ
- [ ] ไม่ส่งซ้ำได้ (ปุ่ม disabled หลังส่ง)
- [ ] ล้างคำตอบเดิมเมื่อส่งสำเร็จ

## UI

- [ ] ดูดีบนมือถือ (<375px), แท็บเล็ต, เดสก์ท็อป
- [ ] สี contrast ผ่าน WCAG AA (ใช้เครื่องมือวัด)
- [ ] โหลดหน้าเร็ว ไม่มี layout กระตุก
- [ ] มี loading / success / error state ที่เข้าใจง่าย

## Accessibility

- [ ] ใช้คีย์บอร์ดได้ครบ: Tab, Enter, Space, ลูกศร
- [ ] focus ring มองเห็นชัด
- [ ] ทุก input มี label ที่ถูกต้อง
- [ ] ไม่มีการสื่อความหมายด้วยสีเพียงอย่างเดียว

## ข้อมูล

- [ ] CSV เปิดใน Excel อ่านภาษาไทยได้ถูกต้อง (ไม่เป็นสระควาย)
- [ ] localStorage ไม่เก็บข้อมูลอ่อนไหวโดยไม่จำเป็น
- [ ] มีปุ่มล้างคำตอบ / เริ่มใหม่

## โค้ด

- [ ] `pnpm build` ผ่าน ไม่มี TypeScript error
- [ ] `pnpm lint` ผ่าน
- [ ] ไม่มี console.log ที่ค้างอยู่ ไม่มีตัวแปรไม่ได้ใช้
- [ ] commit message เป็น Conventional Commits
- [ ] README อธิบายวิธีติดตั้ง/รัน/deploy

## Deploy

- [ ] URL ใช้งานได้จริง ทดสอบบนมือถือจริง
- [ ] ไม่มี env var ลับในโค้ด
- [ ] ทดสอบหน้า 404 และ refresh หน้าย่อย (ถ้ามี)
